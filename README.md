### 🚀 Running the Android Edition
You can open `index.html` directly or serve via local server:
```bash
# From workspace root
node server.js
```
Then visit:
* Local: `http://localhost:3000/android/`
* Android Phone on same Wi-Fi: `http://<YOUR_IP>:3000/android/`
